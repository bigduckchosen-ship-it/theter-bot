# Telegram-бот для мониторинга и быстрой покупки билетов QuickTickets

Умный Telegram-бот для круглосуточного мониторинга театральных представлений театра «Свободное пространство» (г. Орёл) на платформе **QuickTickets** с функцией **покупки билетов в 1 клик с выбором мест в рядах 4–12** и **автоматической передачей сессии пользователю**.

---

## 🚀 Новые возможности и улучшения интерфейса

1. **Мгновенный выбор мест в 1 клик (ряды 4–12):**
   - Интерактивное инлайн-меню с кнопками для **каждого ряда с 4 по 12**.
   - На кнопках отображается количество доступных кресел и стоимость: например, `🟢 Ряд 5 (9 мест, 5000 ₽)`.
   - Нажатие на кнопку ряда **в 1 клик** блокирует лучшие подряд идущие места ближе к центру зала через официальный API QuickTickets.

2. **Бесшовная передача сессии в браузер:**
   - После клика бот блокирует места и генерирует персональную ссылку моста оплаты.
   - При переходе по ссылке браузер пользователя автоматически получает готовую корзину через POST-форму QuickTickets — вы сразу оказываетесь на шаге подтверждения и оплаты с заблокированными местами!
   - Таймер удержания брони: ровно **3 минуты** с живым обратным отсчетом на красивой Web-странице.

3. **Проработанный интерфейс бота:**
   - Карточки спектаклей с постерами высокого качества.
   - Подробная разбивка свободных мест по каждому ряду партера.
   - Настраиваемое количество мест (1, 2, 3, 4, 5, 6 мест подряд).
   - Настройка предпочтительного ряда («Любой лучший ряд» или конкретный ряд).
   - Кнопка моментального обновления статуса без перезапуска поиска.

4. **Круглосуточный мониторинг и авто-бронь:**
   - Сканирование афиши каждые 35 секунд.
   - Режим **Авто-бронь (ВКЛ / ВЫКЛ)**: если авто-бронь включена, бот сам заблокирует появившиеся билеты в 4–12 рядах и пришлет готовую ссылку для немедленной оплаты!

---

## 🛠 Технический стек

- **Python 3.10+**
- **pyTelegramBotAPI (TeleBot)** — управление ботом и клавиатурами
- **Flask** — веб-сервер и мост передачи сессии заказа
- **Requests + BeautifulSoup4** — взаимодействие с QuickTickets API

---

## ⚙️ Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | — |
| `PORT` | Порт для веб-сервера Flask | `10000` |
| `RENDER_EXTERNAL_URL` | Публичный URL приложения (для передачи сессии) | `https://theter-bot.onrender.com` |

---

## 💻 Локальный запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Задайте токен вашего Telegram-бота:
```bash
export BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
export RENDER_EXTERNAL_URL="http://localhost:10000"  # или URL ngrok/сервера
```

3. Запустите бота:
```bash
python bot.py
```
